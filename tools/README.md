# 九分学长本地桥接

网页无法直接控制 Mac 上的桌面应用，所以提供一个只监听本机的轻量桥接程序。

~~~bash
python3 tools/jiufen-bridge.py
~~~

首次运行 macOS 可能要求给 Terminal / Python 开启「系统设置 → 隐私与安全性 → 辅助功能」权限。启动后打开网站的「九分学长」，点击「一键解析当前真题」即可读取当前九分学长窗口中的标题、阅读材料和题目。

内容只在当前电脑之间传递，不上传到桥接服务；点击网站的「保存到复习库」后，仍然只保存在当前浏览器的本地存储中。

桥接会按应用 Bundle ID `com.9fnnn.ielts` 激活九分学长，再读取该应用的可见窗口。它不会读取浏览器内容，也不会上传文章或答案。

如果网页提示自动读取失败，请检查：

1. 九分学长已经打开，并停留在完整的阅读真题页面。
2. macOS「系统设置 → 隐私与安全性 → 辅助功能」中，允许启动桥接的 Terminal（或 Python）控制电脑。
3. 修改权限后退出 Terminal，再重新打开桥接程序。
