# 公开发布规范

这份文档用于每次把 Kiwi 发布到 GitHub 前的自检。

## 可以公开

- 页面结构、CSS 视觉系统和通用 JavaScript 交互。
- 不含个人信息的课程示例、演示数据和产品截图。
- Kiwi 品牌标识、版本记录和产品设计说明。

## 不公开

- `.env*`、`.vercel/`、兑换码、接口密钥和部署配置。
- 个人头像、微信二维码、联系方式和本地文件路径。
- 魔兽争霸原声、游戏角色资源及其他未确认授权的素材。
- 本地原声文件、临时导出文件和教学过程中产生的私人录音。

## 内容迭代约定

1. 新内容先放入对应模块的数据区域或 `content/` 目录。
2. 给每次内容变化写一条 `CHANGELOG.md` 记录。
3. 删除内容时同步删除入口、内容数据和演示文案，避免留下失效链接。
4. 发布前检查公开仓库中没有个人信息、访问凭证或本地绝对路径。
5. 生产环境与 GitHub 作品集分离：GitHub 展示产品能力，线上站点承载实际课程体验。

## 建议的版本号

- `MAJOR`：整体产品结构或公开使用方式发生变化。
- `MINOR`：新增学习模块或一组完整课程内容。
- `PATCH`：修复交互、排版、查词或播放问题。
