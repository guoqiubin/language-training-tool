# Portfolio showcase

这个页面给 GitHub 访客提供一个快速浏览顺序。截图放入 `assets/screenshots/` 后，按下面的顺序补充到 README 或项目介绍中。

## 推荐展示顺序

1. **首页**：展示产品定位、课程价格与训练模块入口。
2. **用户指南**：展示普通学习者如何开始使用。
3. **训练中心**：展示学习等级、进度和模块导航。
4. **口语卡片**：展示英文句子、中文释义、词类颜色、跟读和回复练习。
5. **专项英语**：展示计算机科学与心理学概念卡片的双语内容。
6. **查词卡片**：展示网页端双击单词后的词典弹窗。

## 每张图的说明方式

截图不要只放图片，建议用一句话说明“访客应该看懂什么”。例如：

> 口语卡片把一句完整表达拆成意群、重点词和三种自然回复，适合课堂投屏和跟读练习。

## 截图安全检查

- 不要截到兑换码、个人二维码或个人联系方式。
- 不要截到浏览器地址栏中的本地路径或账号信息。
- 不要展示本地原声文件名、系统文件夹和调试信息。
- 优先使用公开首页、用户指南和演示数据页面。
