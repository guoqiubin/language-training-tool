# Kiwi Content

这里是后续课程内容的公开组织约定。页面交互和课程数据尽量分离，方便持续增加、调整和删除内容。

## 内容分区

- `speaking/`：按语言、难度、场景维护口语句子。
- `vocabulary/`：按主题维护单词、词性、音标、释义和例句。
- `phonetics/`：维护音标、口型、辨音和跟读练习。
- `special-english/`：维护计算机科学、心理学等专业概念。
- `reading/`：维护书信、广告、游戏说明和产品文档等短阅读任务。

当前项目仍然兼容页面内的静态数据，以上目录是未来持续拆分内容时的公共约定，不要求一次性迁移全部旧内容。
